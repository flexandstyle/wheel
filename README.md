# VibeWheel

Сервис для выбора ресторана через колесо фортуны.

## Технологии

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- Zustand

## Запуск

```bash
npm install
npm run dev
```

## Функционал

- Интерактивное колесо фортуны с ресторанами
- Фильтры по району, типу кухни и бюджету
- Каталог всех заведений
- Избранное
- Бонусы от заведений
